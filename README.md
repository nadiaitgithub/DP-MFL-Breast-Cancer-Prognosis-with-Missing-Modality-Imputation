# DP-MFL-Breast-Cancer-Prognosis-with-Missing-Modality-Imputation
DP-MFL is a federated learning framework for breast cancer prognosis, trained on MRI, radiomic, and EHR data across 3 hospitals with differing modality availability. It uses cross-hospital attention to impute missing modalities without centralizing data, predicting molecular subtype and treatment response (pCR).
